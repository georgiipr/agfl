A03 EEGNet: high accuracy, no demonstrated AGFL advantage

15 September 2026 · Four-class BCI IV 2a · Subject A03 · Five matched seeds · Ten completed fits.
Source: Downloads/eegnet-A03-attention. This report embeds the six comparison figures; all 221 original figures are present in the download.

MHA averages 85.56% test accuracy; AGFL averages 84.81%. AGFL minus MHA is −0.74 percentage points. This pilot shows that the current EEGNet pipeline can perform well on A03, but does not establish that AGFL improves on standard attention.

AGFL has 29.67% fewer total parameters. Its observed accuracy is close to MHA's, but this is not a demonstrated non-inferiority or equivalence result. Likewise, the lower observed seed SD alone does not establish superior stability.

The saved elapsed-time measurements are about 1.85 times longer for AGFL in this seven-token configuration. These are whole-run timings, not a dedicated latency, memory or long-sequence scaling benchmark. Fewer parameters therefore must not be described as a measured speed advantage. No new timing benchmark ran locally.

AGFL wins seeds 1, 2 and 4, ties seed 0 and loses seed 3. Its six-trial loss on seed 3 exceeds its combined four-trial gains on the other seeds. Keeping only the winning seeds would misrepresent the experiment.

The saved paired accuracy tests report unadjusted p = 0.794 (paired t) and p = 0.750 (Wilcoxon); both Holm-adjusted values are 1.0 across the supplied metric comparisons. These provide no evidence of superiority here. Five overlapping random splits are not five independent cohorts, so these tests remain exploratory. Absence of a detected difference does not prove equivalence.

Why the earlier A03 result was 86.67%

The preceding study selected between spatial control and segment augmentation separately on validation. Augmentation won seeds 0 and 2, producing a mean selected test score of 86.67%. The current experiment fixes the unaugmented spatial-control recipe for both attention mechanisms. Every current AGFL training history and split exactly reproduces its previous spatial-control counterpart. The difference is the declared experimental procedure, not an unexplained regression.

Integrity and interpretation

All ten runs completed 250 finite epochs, with no failure markers or recorded skipped optimization steps. Within each seed, the complete train/validation/test split, labels, backbone options, preprocessing and training settings match. The split contains 162 training, 54 validation and 54 test trials. The only experiment-setting differences are the attention key and attention-specific options; both use four heads.

Standalone NumPy calculations reproduce all selected validation and test accuracy, macro F1 and macro one-versus-rest ROC-AUC values from saved arrays. The selected epoch is the first maximum validation-accuracy epoch, matching the configured rule. Each checkpoint file matches its diagnostic manifest hash. Diagnostic metadata reports matching reconstructed predictions and source code. Diagnostic IDs and labels match validation, and CSP fitting IDs match training. The recorded A03 source hash also matches the local GDF bytes.

Provenance caveat: the full package inventory differs between the methods. The AGFL records list extra packaging utilities, and record platformdirs 4.4.0 rather than 4.9.4. Source hash, Python, the recorded core scientific-package versions, CUDA, cuDNN and GPU information match. The artifacts do not establish why the full inventory differs; it must not be described as byte-identical environment provenance. The exact differences are preserved below.

This was saved-artifact analysis only. No project imports, training, checkpoint inference, project tests or new physiological data analysis ran locally.

What can go into the paper

A supported statement is: “On the A03 pilot, EEGNet with AGFL achieved 84.81% mean test accuracy over five matched seeds, compared with 85.56% for MHA, with 29.67% fewer total parameters.” This must remain a subject-specific observation. It does not support the submission's broader claim that AGFL outperforms MHA, or establish a 75% average over all nine subjects.

The historical submission's 76.63% versus 72.99% scores belong to its described procedure. They cannot be validated by selecting a high-performing subject from the present four-class experiment. Both attention methods exceeding 75% on A03 resolves the narrow question of whether this EEGNet implementation can learn A03, not whether AGFL is better.

Deferred: nine-subject comparison

Updated direction: improve AGFL on A03 before expanding the study. The new opt-in Q/K/V graph-filter candidates and their training and plotting commands are documented in AGFL/docs/eegnet_agfl_qkv_improvement.md. The commands below retain the earlier expansion proposal for reference; they are not the next experiment. A later broad comparison must use the chosen AGFL method or selection procedure and retain A06.

Use the existing output directory to retain the ten A03 fits. Its historical name remains eegnet-A03-attention, but the extension stores the other subjects beside A03. This is a fixed comparison sweep, not a scope-locked tune-eegnet search. With matching code, dependencies, recordings and saved settings, --skip-completed reuses A03: 80 new fits, 90 total. Changes to those identities can require rerunning affected fits. No model or training defaults were changed in this review.

On the cluster, from AGFL, with the environment active and all nine T-session GDF files in ../ml, train:

python main.py sweep --preset eegnet-a03-attention \
  --set 'data.subjects=[1,2,3,4,5,6,7,8,9]' \
  --output-dir results/eegnet-A03-attention \
  --skip-completed

After successful training, generate signal, embedding and attention diagnostics for every subject and method. Run this block in Bash; it also refreshes existing A03 diagnostics:

for task_run_dir in results/eegnet-A03-attention/eeg/subject_A*/eegnet-*/seed_*; do
  [ -f "$task_run_dir/result.json" ] || continue
  task_relative_run=${task_run_dir#results/eegnet-A03-attention/}
  python main.py diagnose "$task_run_dir" \
    --output-dir "results/eegnet-A03-attention/analysis/diagnostics/$task_relative_run" \
    --device cuda --partition validation --embedding tsne || break
done

Then generate the result figures and paired comparison tables:

python main.py analyze results/eegnet-A03-attention \
  --output-dir results/eegnet-A03-attention/analysis \
  --plots \
  --diagnostics-root results/eegnet-A03-attention/analysis/diagnostics
